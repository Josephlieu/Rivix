## What an AI would need to draft a tech file like this from written specs
Easy (high reliability):
- Header block (style no., description, category, gender, size range, base size, date) and consistent page sequencing.
- BOM tables once the materials are named: fabrics, trims, labels, qty (including "cut length"), colour & finish, placement.
- Construction tables for simple items (seam types, SPI, thread, binding widths, interfacing) - these are largely text.
- Boilerplate pages: colour-approval paragraph, packaging page, test table, label layout (fonts, 3 cm x 5.5 cm layout), bilingual EN/FR text, "Made in Canada".
- Pantone lookups for named colours; consistency checks (e.g. BOM weight vs test minimum; label composition vs BOM) - an AI can actually catch the errors found above.

Medium (needs validated inputs):
- POM tables: an AI can propose points, descriptions, tolerances and a grade rule, but real values (e.g. circumference 22.75 vs 24, brim width) must come from a pattern, block or sample. It must not copy POMs between garments (the maternity panel shows the failure mode).
- Care instructions and care symbols tied to composition: AI can map composition -> ISO/CAN care symbols and translations, but a human must confirm the regulatory text (CAN labelling rules, FR wording).
- Test selection: AI can pick relevant test methods per fabric type (knit vs woven vs membrane) but a compliance/lab person must confirm the standard and threshold.

Hard / needs a human or design tool:
- Flat technical sketches (front/back/side, product-detail callouts, POM measurement diagrams with correct landmark arrows, construction detail close-ups). An AI can write the callout text but cannot reliably draw accurate vector flats; those come from a CAD/illustrator person or a licensed template.
